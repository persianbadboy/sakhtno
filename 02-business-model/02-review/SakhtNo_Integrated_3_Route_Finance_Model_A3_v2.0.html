ماتریس Adopt / Adapt / Build / Reject

ADOPT

  • اعتبار حلقه‌بسته و غیرنقدی
  • دو محصول B2C/B2B روی هسته مشترک
  • تفکیک هزینه بانک و پلتفرم
  • اعتبار گردان و آزادسازی اصل
  • وصول خودکار و freeze حد

ADAPT

  • کارت فقط یکی از کانال‌ها
  • امتیاز بانکی + affordability + رفتار
  • شبکه تخصصی ساختمان و لجستیک
  • تحویل با SKU، مقدار، زمان و عکس
  • tenor بر اساس دسته و ریسک

BUILD

  • Transaction Object یکپارچه
  • اعتبار خدمت اجرایی محدود
  • partial settlement و reversal
  • dispute workflow و hold
  • گیت رسمی تبدیل به Route 3

REJECT

  • پرداخت نقدی آزاد به مشتری
  • POS به‌عنوان تنها evidence
  • ادغام خودکار خریدها در پروژه
  • ماشین وضعیت مشترک B2C/B2B
  • یک tenor برای همه دسته‌ها
